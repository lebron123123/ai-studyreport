# 0907 知识审核发布闭环技术验收

## 交付范围

搜索结果提取原文后，同页展示正文、来源及分类供管理员核对；支持单项、批量审核通过并发布。不再要求前往资料台账或 Wiki 二次发布。普通用户仍只能投稿。

政策、政策解读等按分类进入正式资料台账；经验类进入 Wiki。两条路径均在发布时建立 RAG 向量、精确文本及检索台账。原投稿的 Wiki 标签不决定最终分流，实际审核分类决定目标。

历史已通过但未发布的资料在已通过列表提供发布入口。独立发布或归档的 Wiki 不会被此入口覆盖。

## 责任文件

- functions/api/_contribution-publish.js：正文校验、模型超时、数据库原子发布、幂等回执。
- functions/api/contributions.js：管理员鉴权、状态校验、审核与发布入口。
- admin-contribution-batch.js：分类确认、批量发布、失败重试和发布结果展示。
- admin-source-search.js：搜索提取后同页核对发布、同步结果状态。
- tests/contributions-api.test.js 与 scripts/contribution-transaction-smoke.mjs、admin-contribution-smoke.cjs、admin-source-search-smoke.cjs、admin-review-live.mjs：权限、事务、浏览器与运行服务验证。

## 边界

本次原子发布面向当前本地 PostgreSQL 部署，可迁移到相同架构的机房服务器；未支持 Cloudflare D1 的跨库原子发布。未自动批准真实资料。未对真实政策效力作法律判定，仍须管理员核验正文、来源和适用范围。无法提取原文不能用搜索摘要冒充正文发布。模型超时会保留已审核未发布状态供重试。既有 independently published Wiki 应在 Wiki 页面管理。未执行 Git 提交或推送。
