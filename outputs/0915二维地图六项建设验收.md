# 0915 二维地图六项建设验收

## 交付范围
1. CSV/JSON台账导入、只读正式项目读取、重复保护和人工坐标确认。
2. 行政区、类型、阶段、名称筛选及地图列表联动。
3. 项目指标、来源、照片链接与资料链接。
4. 红线绘制/GeoJSON导入、近似面积和距离量算。
5. 500/1000/2000米范围，轨道、公交、教育、医疗、商业、产业园区六类查询；最近返回地铁点直线距离。
6. 独立历史快照、来源时间范围与备注、JSON研判包下载/恢复、HTML简报。

入口：主站左侧项目地图 → 二维项目研判。3D没有继续开发。
研判包是手动下载保存，不是服务器自动持久化。正式项目只读，修改只影响本次研判副本。
