## 范围与现状

## 根因与修复
- 主搜索服务 HTTP 200 但 status=incomplete / max_output_tokens，或未真实执行搜索工具；不能视为检索完成，更不能把模型自行书写的网址当成证据。
- 原备用通道 fetch failed；批量页面将 errors 隐藏为暂无结果。现在保留可操作错误、标记失败并允许仅重试失败项。
- 新增 Bing RSS 独立备用，设有超时与关闭开关 WEB_SEARCH_BING_DISABLED=1。维持原有证据质量与人工审核门槛。
- AGENTS.md 增加本次事故准入规则，包括工具执行验证、备用隔离、真实接口验收及报告失败逐节定位。
