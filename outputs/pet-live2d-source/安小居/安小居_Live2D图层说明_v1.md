# 安小居 Live2D 分层素材 v1

基准图：`outputs/pet-video-source/安小居/安小居基准待机.png`。

本版本用于先完成三个核心交互：待机呼吸、眼球跟随鼠标、左右手靠近互动。跑步、跳跃、翻滚、背面移动和变身继续使用现有视频，不由本模型替代。

## 图层结构

- 表情：左眉、右眉、嘴。
- 眼睛：左眼球、右眼球、左右眼白补底。
- 前景主体：屋顶、主体脸部、中央尖角、左右臂、左右腿鞋。

## Cubism 导入后顺序

1. 先检查所有图层叠加后是否与原图一致。
2. 自动生成 ArtMesh，边缘和眼球改用较密网格。
3. 建立总身体、左右眼球、左右手臂变形器。
4. 先制作 `ParamEyeBallX`、`ParamEyeBallY` 和呼吸，再制作手臂互动。
5. v1 暂不制作大角度转头；Live2D负责小幅实时互动，四向跑动继续调用视频。
