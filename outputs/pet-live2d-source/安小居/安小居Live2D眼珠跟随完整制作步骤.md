# 安小居 Live2D 眼珠跟随完整制作步骤

适用工程：`安小居_Live2D模型_v1.cmo3`
适用软件：Live2D Cubism Editor 5.3
当前可用结构：外层 `EyeTracking` → 内层 `111` → `Iris_R_Tracking`、`Iris_L_Tracking`

## 一、为什么采用两个嵌套变形器

- 内层变形器只负责眼珠左右移动（眼球 X）。
- 外层变形器只负责眼珠上下移动（眼球 Y）。
- 两个方向可自动叠加形成左上、右上、左下、右下，无需手工制作复杂的3×3九宫格关键点。
- 眼白、眉毛、嘴和脸部不放进变形器，因此鼠标跟随时只有两颗蓝色眼珠移动。

## 二、先整理名称和层级

1. 先按 `Ctrl + Shift + S` 另存为：`安小居_Live2D模型_眼球跟随_v2.cmo3`。
2. 把外层 `EyeTracking` 重命名为：`EyeTracking_Y`。
3. 把能正常拖动的内层 `111` 重命名为：`EyeTracking_X`。
4. 最终层级必须是：

```text
EyeTracking_Y
└─ EyeTracking_X
   ├─ Iris_R_Tracking
   └─ Iris_L_Tracking

Mouth、Brow_L、Brow_R、EyeWhite_L、EyeWhite_R、BodyFace
必须位于这两个变形器之外。
```

如果 `EyeTracking_Y` 之前错误绑定过“眼球 X”，先选中它，删除“眼球 X”上的关键点并恢复默认形状；外层以后只绑定“眼球 Y”。

## 三、制作左右看（眼球 X）

### 1. 建立关键点

1. 在“变形器”列表选中 `EyeTracking_X`。
2. 在“参数”面板找到“眼球 X”。
3. 点击“眼球 X”这一行。
4. 点击参数面板顶部“三个绿色点带 `+`”按钮。
5. 确认参数出现 `-1、0、1` 三个关键点。

### 2. 设置三个姿态

- `0`：正视，保持原样，不修改。
- `-1`：向画面左侧看。选中左关键点后，把 `EyeTracking_X` 整体向左移动约6～8个屏幕像素。
- `1`：向画面右侧看。选中右关键点后，把 `EyeTracking_X` 整体向右移动约6～8个屏幕像素。

移动时必须在“变形器”列表选中 `EyeTracking_X`，不要直接点击或拖动蓝色眼球图层，否则会修改三个关键点共用的基础位置。

### 3. 左右验收

拖动“眼球 X”滑块测试 `-1 → 0 → 1 → 0`：

- 两颗眼珠同时、同方向、同距离移动。
- `0` 时必须准确回到正中。
- 眼白、眉毛、嘴和脸完全不动。
- 眼珠不得接触眼睛黑色外轮廓，左右极限仍应留出明显眼白。
- 移动过程连续，不突然跳到另一位置。

## 四、制作上下看（眼球 Y）

### 1. 建立关键点

1. 先把“眼球 X”恢复到 `0`。
2. 在“变形器”列表选中外层 `EyeTracking_Y`。
3. 在“参数”面板找到“眼球 Y”。
4. 点击“三个绿色点带 `+`”，建立 `-1、0、1` 三个关键点。

### 2. 设置三个姿态

- `0`：正视，保持原样。
- `-1`：向下看。把 `EyeTracking_Y` 整体向下移动约4～6个屏幕像素。
- `1`：向上看。把 `EyeTracking_Y` 整体向上移动约4～6个屏幕像素。

上下幅度应小于左右幅度。安小居眼睛较大，上下移动过多容易露出眼白补底边缘，显得像眼球脱框。

### 3. 上下验收

拖动“眼球 Y”滑块测试 `-1 → 0 → 1 → 0`：

- 两颗眼珠同时上下移动。
- `0` 时回到正中。
- 眼球不能碰到上下黑色轮廓。
- 眼白和脸部不能一起移动。

## 五、测试九个方向

分别测试以下组合：

| 方向 | 眼球 X | 眼球 Y |
|---|---:|---:|
| 正中 | 0 | 0 |
| 左 | -1 | 0 |
| 右 | 1 | 0 |
| 上 | 0 | 1 |
| 下 | 0 | -1 |
| 左上 | -1 | 1 |
| 右上 | 1 | 1 |
| 左下 | -1 | -1 |
| 右下 | 1 | -1 |

九个位置均正常后，把两个参数恢复为 `0`，按 `Ctrl + S` 保存。

## 六、常见问题及恢复

### 1. 切换到另一个关键点，眼珠没有回中

原因：拖动了 `Iris_L/R_Tracking` 图层本身，而不是变形器。
处理：立即按 `Ctrl + Z`，重新从“变形器”列表选中 `EyeTracking_X` 或 `EyeTracking_Y` 后再移动。

### 2. 拖动时整张脸一起移动

原因：误选了 `BodyFace`，或者脸部被放进眼球变形器。
处理：按 `Ctrl + Z`；检查层级，眼球变形器下面只能有两颗眼珠。

### 3. 无法拖动旧变形器，新建变形器却可以

原因：旧变形器可能残留错误关键点、锁定状态或错误父子关系。
处理：保留已验证可拖动的新变形器，重命名后作为正式控制层；不要继续在异常旧变形器上反复修改。

### 4. 眼珠移动幅度太大

判断标准：眼珠靠近或碰到黑色眼眶轮廓、斜眼感明显。
处理：按 `Ctrl + Z` 后重新移动原距离的一半；左右约6～8像素、上下约4～6像素只是起始参考，以视觉边界为准。

### 5. 只移动了一颗眼珠

检查 `Iris_R_Tracking` 和 `Iris_L_Tracking` 是否都位于 `EyeTracking_X` 下面；不要把眼白放进去。

## 七、网页接入原理（简要）

网站获得鼠标相对宠物中心的位置后，将水平距离映射到 `ParamEyeBallX` 的 `-1～1`，垂直距离映射到 `ParamEyeBallY` 的 `-1～1`。代码再做平滑插值和最大幅度限制，眼珠就会持续而自然地看向鼠标。

Cubism阶段只负责把两个参数和眼珠动作制作正确；网页跟随、靠近互动、平滑速度和离开后回正由后续代码完成。
