需求日期：2026-10-19；证据时间使用UTC，部分为2026-10-20。本次本地实现版本20261019.1，普通非提权沙箱只读检查通过。未提交、推送或部署；已有用户修改保留。本文属于仓库模块技术验收记录。

## 1. 实际完成及使用方法

在后台“AI生成规则、审核规则与逻辑”的可研逻辑区域，新增“下载最新逻辑表”面板。选择出租类或改造项目场景后，可下载当前类型；也可以展开批量选择，勾选多个类型并一次下载一个Excel。编辑状态另提供编辑稿下载，标注“未发布、未保存”。发布和保存逻辑保持原操作流程。

默认导出每次点击时服务器最新已发布版本，不使用打开页面时的旧快照。批量面板打开后发生新发布，也会在点击下载时重新读取。导出接口不写数据库、不初始化种子、不发布、不调用AI、不修改任何项目正文。

| 工作表 | 实际内容 |
| --- | --- |
| 版本总览 | 类型/场景、正式或编辑稿状态、业务逻辑版本、数据库版本、发布时间/发布人ID、快照和导出时间、章/节/逻辑点数量、对比基线和来源 |
| 全篇逻辑 | 当前生效全文要求；原存储配置完整保留 |
| 章节与小节逻辑 | 每个逻辑点一行，含章节、小节、细分标题、所需资料、获取渠道、当前执行写作逻辑、输出要求、缺失处理与适用限制 |
| 专业成稿标准 | 全篇行文规范、九种小节类型各自的要求/示例/完整执行说明、直接成稿硬要求，区分后台配置和当前程序默认 |
| 版本变化 | 与上一真实发布版逐字段对照新增、删除、修改；无历史时明确标注，编辑稿对比点击时的已发布版 |

导出原文不经AI改写。当前执行逻辑按已有共享写作规范投影，原始存储JSON另保留在默认隐藏列；可在Excel取消隐藏查看。超长单元格按“文本分段”连续保留，文件不截断。宽列、自动换行、冻结表头与前三列、筛选和自适应行高已核验；超长内容仍可在编辑栏查看全文。
