# 月度XIRR及年度IRR对照

## 实现与口径

- nrcalc.js：monthlyCashflow逐月记录，日期固定每月1日；工程及利息复用原月度计划。收入、收楼、分成按月度爬坡权重，运营按有效月份（开办费首个运营月），摊销按运营月份。
- 保持年度会计口径：增值税及附加按当年收入权重分配，印花税首个运营月。所得税按年内累计利润及既有年度弥补亏损计算累计计提差额，允许冲回；末月与年度税额核对，不代表真实预缴及汇算清缴现金时点。独立reconciliation字段展示四舍五入差额。
- XIRR按实际UTC天数/365求根；无正负现金流或无找到有效根返回空值，不伪造0。多根以接近10%初值者为选择规则；搜索log-rate范围[-16,16]，非传统现金流可能多根，不承诺Excel所有初值下同根。
- calc.js：表底新增月度XIRR、年度IRR，全周期列显示收益率、年份列留空。原顶部年度IRR保留；本轮仅新增对照。恢复旧结果时重算缺少月度现金流的数据，不改正式经验库记录。
- export.js：相同两项指标，增加月度现金流工作表，日期为Excel日期数字，净现金流公式及真实XIRR/IRR公式；页面与导出取相同模型数据。index.html缓存版本更新。
