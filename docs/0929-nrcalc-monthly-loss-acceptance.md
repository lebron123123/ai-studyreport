# 0929 非居改保月度补亏验收记录

## 结果与精确口径

只修改非居改保；出租、出售原有亏损结转不变。旧非居改保年度五年补亏及年内所得税差额算法用JavaScript块注释隐藏、加“# 停用”标记保留，不提供用户切回旧方式的选项。

令上月累计利润为S、本月利润为P：首月补亏0；S+P>0且P>0且S<0时补亏=-S；S+P<0且P>0时补亏=P；其他为0。计税基础=P-补亏，所得税=max(计税基础,0)×配置税率；后月亏损不冲回已计提税额。累计跨年延续，无旧年度五年截断。严格保持原表累计恰好归零时补亏0的特殊条件，不能以看似更合理的MIN公式代替。

年度补亏、计税基础、所得税和净利润仅逐月汇总；新税额进入现金流/NPV/XIRR原链路。其他收楼、运营、利息、工程摊销、VAT口径不在本次变更范围。
