## 改动及责任模块

1. `report-writing-standard.js`：生成硬规则明确禁止“这个小节主要讲/主要分析”“本节旨在/将从/围绕”“本章重点介绍”等内容预告和写作方法开场白；旧自定义配置也不能把硬要求省掉。检查扩展同义句识别。必要的真实业务背景、因果、测算依据和不确定条件保留，不用正则删除旧稿。
2. `functions/api/_report-writing-policy.js`：内容规则版本与配置结构版本分别治理，避免为更新文风破坏旧配置。
3. `functions/api/reportexecution.js`：整节及定点返修都使用相同直接成稿硬要求。定点返修只要求保留该编辑目标实际包含的保护标记，未编辑邻段仍由程序原样保留；禁止把全项目待补标记复制进每个补丁。追加正文最多两句，不再复制整段长文进追加目标。
4. `report-completion-contract.js`：只有已有匹配冻结表时，缺表才允许通过引用原表返修。没有原表或原表不匹配仍阻断，不编造表、不改数字、不取消表格要求。
5. `index.html`：更新通用行文及成稿检查资源版本，刷新后加载新规则。未更改目录、章节结构、各类型业务规则或财务公式。
6. `tests/report-writing-standard.test.cjs`、`tests/report-writing-policy.test.mjs`、`tests/report-execution-quality.test.mjs`：覆盖旧配置、跨类型共用硬要求、禁用开场白/保留真实因果、已有冻结表返修与无表阻断。
7. `scripts/check-report-generation-recovery.mjs`：真实代表节/43节有限预算复验、模型重叠、元叙述、正式数据保护、相邻API及精确副本清理。`scripts/report-main-flow-smoke.cjs`：旧测试页补齐正式页面已必需的行文/成稿模块，并显式设置测试项目名称的背景职责；保留事实职责门禁。
