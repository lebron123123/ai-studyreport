# 1015 上传报告完善：通用修改标红对照功能

日期：2026-10-15。状态：通用功能已实现，模块、浏览器和 Word 实际排版验证已通过，最终冻结版本的完整回归进行中。

## 用户范围与责任

用户确认本次是网站的通用“在上传原稿基础上完善报告”功能，不是只修订税务局报告。任何可解析的 Word 主稿均使用同一份导入基线、采用记录与导出模块；测试不得以外部手工改好一个特定报告代替网页工作流。

输入为保留原件、核验过的解析位置和网站内已采用候选；输出为网页净差异、当前工作稿，以及独立下载的固定红字对照版、当前工作稿 Word。另提供可选 Word 原生修订版。待审、拒绝、撤销内容不得写入。上传时已经在外部修改过的文件没有本网站历史，不能逆推其改动。

责任模块：`report-import-review.js` 继续负责采用投影和字符差异（不扩张事实权限）；`report-import-delivery.js` 负责新 Word 包与修订标记；`report-import-ui.js` / `report-import.css` 负责查看、图例及下载入口；`index.html` 只更新已自测模块的资源版本。数据库、AI 请求及正式项目不在本次修改范围。

风险按高风险导出链路处理：模块先验，再集成入口，真实 index 隔离浏览器路径与真实 DOCX 排版核验后执行最终完整独立 PostgreSQL 回归。全程零真实 AI 请求，不重放历史不确定请求，不覆盖原件或用户修改，不提交/推送。

## 验收要求

- 以最初上传主稿为基线，显示当前已采用内容的净差异；连续改写、部分采用和撤销保持一致。
- 网页区分修改标记、当前工作稿和导入原文。新增红色下划线、删除红色删除线；待补提示与修改标记有清晰说明。
- 默认 Word 对照版固定新增红色下划线、删除红色删除线；当前工作稿仅保留当前正文与完整待补提示。原件已有格式/修订不得被误当成新修改。可选原生修订版支持接受/拒绝，颜色受阅读软件作者配色设置影响，不承诺固定红色。
- 未采用、拒绝、撤销不进入导出；无净改动保持原件逐字节一致。表格、图片和未改部件保持原样；复杂原段或超限差异不能静默损坏输出。
- 原件哈希与位置校验失败阻止导出，页面提示可操作错误，已有稿件仍保留。
- 覆盖空数据、加载、失败、重复下载、刷新、返回再进入；三种下载来自同一采用状态。
- 至少使用不同业务文本的通用样例和真实原件回归。模拟候选明确为测试数据，不作为 AI 质量证据。

## 三种 Word 的用途与边界

默认修改标红对照版是固定文字格式：新增红字下划线、删除红字删除线，删除内容真实保留。用于看清修改，不能将其当作没有删除文字的最终正文；需要当前正文应下载当前工作稿。此版本只改主文档部件，不改变 Word 设置。

可选 Word 修订版保留本轮原生增删修订，供 Word 等支持修订的软件接受/拒绝。实际 LibreOffice 排版已证实，原生修订色会被软件的作者配色覆盖，因此不能用它承诺固定红色，也不修改用户软件设置。默认对照版和可选修订版分开提供正是为解决这一问题。

比较基线固定为本次上传的主稿，不将外部预先修改的版本倒推为网站生成历史。原件原有红字、表格、图片、旧修订和其他未改部件保留。当前工作稿只去除本功能新增的修改标记，不擅自接受原稿本来就有的修订。

复杂格式段落可补充，暂不直接改写；现有保护继续生效。长段落超过逐字比较能力时显示完整整段对照并明确提示，不截断正文。分页仍取决于用户的 Word/WPS/字体和原模板，不以合成样例代替任意长报告的正式分页验收。原生修订版的“全部接受/拒绝”也会处理原件原有修订，应由审阅人选择相应修改；默认静态对照版不能一键接受，当前正文可直接下载当前工作稿。

通用不等于无范围限制：主稿须为 `.docx`；当前完善对象为正文段落，标题、表格、图片和复杂内容继续受保护。原有每次最多10段、12000字、补充最多1500字的限制保持，没有新增一键自动改完整篇的承诺。导出回执仍是 `layoutVerified:false`，不会因本轮合成样例排版通过就把任意用户稿标为完成验收。

本功能继续以独立导入稿 ID、原件和已采用记录工作，没有写死税务局名称、素材路径或正式项目写入入口。失败下载不触发 AI；AI 的原有一次派发与未知不补发规则保持。当前只是本地网站功能交付，未发布公网；本轮没有新增真实 AI、没有重启服务、没有修改数据库/生成后端，也不重新认证前轮的专业内容质量或旧 AI 超时根因。
