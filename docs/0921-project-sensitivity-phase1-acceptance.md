## 边界

- 首期仅支持完整月度非居改保项目；不完整/旧年度模型明确要求先核对保存，不以默认值伪装真实数据。
- 所有输入均进覆盖台账，不意味着派生字段、模式标识也作为独立因素排序。公式配置固定并完整展示。
- 排名取两端最大绝对变化；不同变量范围/单位会影响排名。单因素分析不识别交互效应，也不是实际预测或因果证明。
- 基准固定本次后台公式配置；JSON 保留配置，不能将其说成项目历史配置重放。
- 保存分析版本是本机 JSON 下载，不是后台持久化或刷新恢复。无自动发布全局权重。
- 缺口沿用现有净现金流口径，不等同资本金融资缺口。
- 项目列表沿用既有 API 返回范围；没有新增跨分页全库加载功能。
