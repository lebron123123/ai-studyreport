## 实现

- md.js、report-output-policy.js：兼容TABLE内表名、大小写、两列表及缺失闭合；避免括号续行吞掉下一表行。
- report-section-layout.js：标准表无法匹配的字段保留为补充明细；原表有未覆盖内容时保留原表核对，不以套模板为由静默删除。
- export.js：嵌套容器和失效模板标识保留实际表格输出。
- report.js、report-output-policy.js：生成和修改采用同一章节预算；以约36000字正文规划，依据清单少写，财务、风险、工程等重点加权，单节规划上限1200字。预算不包含表格，不是截断上限，也不是页数保证。新增可折叠篇幅检查。规则版本更新让已有正文进入候选复核，而非自动覆盖。
- 模板提示提供完整行列结构，而非仅表头。表名要求在TABLE标记外。
