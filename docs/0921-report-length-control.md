# 同类可研篇幅控制：实施边界与本轮结果

## 机制说明

不是仅手工改龙岗，也不是仅增加一句“少写”的提示词。通用流程应分为：统一章节职责和字数预算 → 依据材料写候选 → 核对跨节重复、表格字段及事实 → 实际Word排版 → 对超长责任小节定向精简 → 人工接受。原件、旧稿、已有候选保持不变。

当前report-output-policy.js已有与材料长度解耦的36000字全篇规划、单节1200字规划上限、章节权重、依据清单例外和全篇职责目录；report.js已有超预算/完全相同段落重复提示。以上是规划和诊断，不是自动硬截断或页数保证。表格不计入正文预算，所以仅此仍不足以限制页数。

内部精简目标约110页，标准版上限120页；不足目标不凑长。使用相同版式、目录和必要表格口径；材料增加不自动增加正文篇幅。特殊业务事实、必要风险或专业附表无法压缩时必须明确列出例外，不能承诺所有项目页数相同。既有“超页仍然下载”的用户确认保留，但不得将该版本标为标准达标。

后续尚需完成：表格逐字段人工语义核对及去重候选、基于真实排版的章节超长回馈、精简后事实完整性审签。这些尚未闭环，不宣称今后所有报告自动达标。不得新增付费AI无限重试或自动覆盖候选。
