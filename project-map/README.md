# 深圳项目地图（独立按需加载模块）

输入仅为当前项目名称、已确认高德坐标及坐标体系。输出仅供浏览；搜索不会覆盖项目位置或触发报告保存。搜索复用现有鉴权 `/api/poi`，iframe 不接收令牌和报告资料。模型与第三方引擎不进入 localStorage。

路线：二维全市地图 ↔ 统一三维城市（普通楼体＋原位置精细模型）。左侧为可筛选的项目/地标索引，点击飞抵，不再打开独立模型库。提供有限轮次自动巡游、当前位置环绕、返回项目、恢复视角；人工拖动、切换模式、后台或关闭停止巡游。全市底图目前联网使用 OpenFreeMap；不是已离线导入完整深圳数据，内网部署需替换瓦片服务。模型复用 linranff/GTA_SZ 作者地理资产，不复制游戏主循环。

模型通过 `scripts/import-city-models.ps1` 从用户 ZIP 精确导入，保留清单与 SHA256。用户于2026-09-13确认已与作者沟通允许借鉴升级；此确认不扩大第三方素材授权。只导入基础地标、精细地标和关联地形数据，不导入人物、车辆、天空HDR等素材。作者坐标原点 [114.025,22.536]，比例0.60；模型预览保持原比例，不用于尺寸/日照测量。城市地标不是安居项目资产。

浏览器退出 iframe 销毁全部渲染上下文；三维模型通过Babylon共享MapLibre上下文，不另建第二个画布。进入三维且缩放达到14级才加载模型；静止不持续触发渲染，后台停止巡游。当前两份合并GLB整体加载，共4,429,128字节，尚未按建筑分片；地图与搜索仍需网络。300人业务压测结论不适用于新增地图资源。

## 本地依赖与数据范围

vendor 固定版本：MapLibre GL JS 5.6.1（BSD-3-Clause）、Babylon.js及loaders 8.56.2（Apache-2.0）、meshoptimizer 0.25.0（MIT）；各许可证随文件保存。下载来源为 unpkg 对应版本包。引擎不通过动态CDN加载，meshopt解码器也指向本地文件。

13个目录条目不等于13个独立模型：核对GLB节点后，10处有模型，其中作者6处精细模型全部保留；深圳湾公园、人才公园、香蜜湖为地图定位条目。模型按作者原点和比例转入地图坐标，属于展示级配准，不是测绘级校核。模型就绪才按作者替换轮廓隐藏对应普通楼体，切回二维恢复过滤；不修改原始地理数据。轮廓简化与估算模型可能存在局部差异。

## 照片建模与持续更新边界（参考用户提供方案）

本轮未实现照片上传建模、模型审批或发布后台。后续接口须分开管理项目业务状态、照片证据、几何模型；照片记录拍摄/上传时间、项目/楼栋、方向、原件哈希和权限。原件进入本机或服务器对象存储，不装入浏览器缓存。

模型清单须包含项目/楼栋ID、WGS84定位、原点/单位/旋转、覆盖范围、LOD、大小/哈希、来源授权、版本与日期。照片不足时只作现场图片或明确标注的估算外观，不宣称自动得到准确模型。采用候选→人工校准→授权发布→可回退，业务数据更新不强制重建模型。重建任务放后台隔离队列，不占报告保存链路；本模块目前仅消费静态已导入模型。

已吸收：原有10处模型、6处精细几何、地理索引、地点飞抵、环绕观察和有限巡游。尚未吸收：作者整套植被/道路/地形效果、日夜天气、完整城市摄影机系统；不包含角色、驾驶、战斗等游戏系统。未获得的全市地标资产不能用占位模型冒充。

入口：AI可研的项目位置搜索旁“二维地图 / 三维周边”。可直接访问 `/project-map/index.html` 查看城市；搜索须从项目入口打开，以复用现有登录权限。修改不涉及数据库、测算、保存协议。
