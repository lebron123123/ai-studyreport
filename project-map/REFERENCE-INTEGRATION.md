# 原版城市图形接入核查（2026-09-13）

## 上一版缺口

上一版接入了10处地标几何，但普通建筑仍是MapLibre拉伸楼体，未接入原版窗格立面、建筑材质多样性、HDR光照和CityObserver观察器。因此不是原版城市视觉的等效移植。

## 本轮范围

- `detailed-city.mjs`：独立图形场景，替代三维模式中的拉伸建筑；二维入口仍为MapLibre。
- `reference/`：从用户本地“深圳精细城市探索版”机械转译10个图形/观察模块。来源文件SHA256、资产清单见`reference/import-manifest.json`，再导入脚本为`scripts/import-city-graphics.mjs`。
- 原版建筑、道路、地标、窗格分块、纹理与环境资产共199个文件、170,012,364字节（含许可文件）。这是服务器/本地静态资源体积，不等于首次下载或浏览器内存。
- 没有导入DrivingWorld、车辆、行人、战斗、游戏物理。
- 复用原版WASD、QE、方向键、拖动/缩放；增加0.25～4倍移动速度。Shift再加速遵循原版。
- 初始二维不请求三维模型；三维立面按附近街区装入/释放；隐藏页面停止绘制；切回二维销毁三维引擎。当前主建筑49,728,080字节仍整包加载，不声称完成全城分块。

## 数据边界

原版记录16,076栋建筑，范围约113.915～114.135E、22.497～22.575N，并非深圳全市。建筑高度含OSM楼层换算与类型估计。未获得真实测绘、日照或楼内数据，不支持据此直接作工程结论。照片建模、版本审批和新增项目模型持续更新仍是后续工作。

## 验证口径

13项地图/坐标/检索/观察器行为测试通过，0失败、0跳过。首次浏览器验收发现Meshopt解码器默认依赖外网，已改为本地文件；发现手动停止巡游误清空移动键，已调整事件顺序。浏览器最终结果以`city-detail-smoke.cjs`最新运行记录为准，不沿用之前简化地图的验收。

44维沿用当日基线：覆盖73.84、生产成熟度74.92、真实数据资产64.33，未提高或降低综合评分。本轮图形重用不证明生产容量。优先事项：最终机器上的画质/帧率和内存测量；普通建筑进一步分块；真实项目模型配准与版本审批。

最终隔离Edge浏览器验收通过：腾讯地标原版场景1760个网格（含附近立面）；黄昏/白天截图人工核对；W键实际移动、速度/地面/高空各5次操作；页面未捕获新增脚本错误；返回二维后Babylon引擎实例为0；初始二维三维资源请求为0。现场8080静态页面、场景脚本和城市元数据均返回200。未将引擎内部FPS采样冒充真实绘制帧率，未执行显卡性能压力测试、全站回归或全部地标逐一视觉验收。

源码统计：671文件、22,099,409字节、21.08MiB、121,326行（固定源码与配置口径；不含GLB/HDR/PNG资产）。
